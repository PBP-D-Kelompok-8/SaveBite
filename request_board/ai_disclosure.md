# Pengungkapan Penggunaan AI

Dalam pengembangan modul **Food Rescue Request Board** pada proyek **SaveBite**,
saya menggunakan **OpenAI Codex** dan **Google Gemini** sebagai alat bantu dalam
proses desain, implementasi antarmuka, serta pengujian. Pengungkapan ini menjelaskan
ruang lingkup penggunaan AI pada bagian yang saya kerjakan.

## Penyusunan UI dan Desain Figma

Saya menyusun UI dengan bantuan Codex dan Gemini untuk mendiskusikan kebutuhan
tampilan serta memperoleh panduan penyusunan desain di Figma. Bantuan tersebut
mencakup saran mengenai tata letak, hierarki informasi, susunan komponen, dan
konsistensi visual agar alur penggunaan modul lebih mudah dipahami. Saran AI
menjadi bahan pertimbangan dalam mengembangkan dan menyempurnakan rancangan.

## Implementasi Desain ke Website

Saya juga menggunakan bantuan AI untuk menerjemahkan desain dan aset pada file
Figma menjadi UI website Food Rescue Request Board. Proses ini mencakup bantuan
dalam menyusun struktur HTML atau template Django, menyesuaikan CSS, serta
mengintegrasikan tampilan dengan kode proyek yang sudah tersedia. Implementasi
dikembangkan secara bertahap melalui penyesuaian antara rancangan Figma dan hasil
tampilan pada website.

## Testing, Debugging, dan Edge Case

Codex digunakan untuk membantu menyusun dan menjalankan pengujian, menelusuri
penyebab masalah, serta memperbaiki perilaku yang belum sesuai. Pengujian juga
mencakup edge case, seperti input yang tidak valid, pembatasan aksi berdasarkan
kepemilikan data, dan perubahan status permintaan. Bantuan ini digunakan untuk
memeriksa apakah tampilan dan interaksi modul tetap berjalan sesuai aturan pada
berbagai kondisi penggunaan.
